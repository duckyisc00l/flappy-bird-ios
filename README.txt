FLAPPY BIRD (v117) - iPhone app project

What this is: the HTML game (App/web/index.html) inside a tiny iPhone app.
GitHub builds the .ipa for you on a Mac in the cloud.

1. On github.com make a new repository (Private is fine).
2. Upload EVERYTHING in this folder, keeping the folders (App, .github, project.yml).
   (On a computer: "Add file" > "Upload files", drag the whole folder in.)
3. Open the "Actions" tab > "Build Flappy Bird IPA" > "Run workflow".
4. When it turns green (about 3-5 minutes), open the run and download "FlappyBird-ipa".
   Unzip it: inside is FlappyBird.ipa.
5. Install it on your iPhone with Sideloadly or AltStore (they sign it with your Apple ID).
   With a free Apple ID the app must be re-signed every 7 days.

To update the game later: replace App/web/index.html with a newer version and upload again.
